# MicroLLM-CPP

A minimalist, autoregressive Neural Network engine written from scratch in pure C++ (Standard Template Library only), without any external Machine Learning frameworks.

## О проекте (Why I built this)
Проект был разработан исключительно из инженерного и исследовательского интереса. Главная цель — разобраться "под капотом" в математике и архитектуре языковых моделей: от работы с матрицами в оперативной памяти до ручного вычисления градиентов.

## Архитектура и технические детали
Модель представляет собой **Многослойный перцептрон (MLP)**, работающий по принципу предсказания следующего слова (N-gram Language Model).

*   **Tokenization:** Кастомный парсер, который очищает текст от пунктуации, приводит к нижнему регистру (`std::tolower`) и формирует словарь.
*   **Encoding & Context:** Использование One-Hot Encoding. Для понимания смысла используется архитектура **Sliding Window**: на вход подается склеенный вектор из 3 предыдущих слов.
*   **Network Layers:** Входной слой (Склейка 3-х слов) ➔ Скрытый слой (с функцией активации ReLU) ➔ Выходной слой.
*   **Learning:** Ручная реализация алгоритма обратного распространения ошибки (**Backpropagation**) и градиентного спуска (Gradient Descent) с настраиваемым `LearningRate`.
*   **Generation:** Авторегрессионный цикл. Для выбора следующего слова используется функция **Softmax** и алгоритм взвешенной рулетки с параметром **Temperature** (семплирование через `std::mt19937`).
*   **Serialization:** Возможность сохранения обученной матрицы весов в бинарный дамп (`brain_base.bin`) через `std::ofstream` и моментальная загрузка при следующем старте.

## Стек технологий
*   **Язык:** C++ (С++17/20)
*   **Библиотеки:** Только STL (`<vector>`, `<string>`, `<fstream>`, `<random>`, `<cmath>`, `<algorithm>`)

## Как это работает
1. Программа считывает сырой текст из файла.
2. Формирует уникальный словарь.
3. Разбивает текст на обучающие выборки: `[Слово 1] [Слово 2] [Слово 3] -> Target: [Слово 4]`.
4. Обучает сеть заданное количество эпох.
5. Принимает 3 стартовых слова от пользователя и самостоятельно генерирует осмысленное продолжение текста, основываясь на выученных вероятностях.

*Примечание: Из-за использования One-Hot Encoding (без Embeddings слоя, был добавлен, но вырезан) для избежания "смысловых галлюцинаций" при генерации рекомендуется использовать низкую температуру (Greedy Search, Temperature ~0.01 - 0.1).*
